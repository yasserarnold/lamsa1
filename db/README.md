# db/ — سكربتات قاعدة البيانات

مولّدة آليًا من قاعدة البيانات الحالية عبر:

```bash
bash scripts/dump-schema.sh
```

| الملف | المحتوى |
|---|---|
| `01_types.sql` | أنواع Enum |
| `02_tables.sql` | الجداول + القيود + الفهارس |
| `03_functions.sql` | دوال قاعدة البيانات |
| `04_triggers.sql` | المشغّلات (Triggers) |
| `05_rls_policies.sql` | تفعيل RLS + السياسات |
| `06_grants.sql` | صلاحيات الجداول والدوال |
| `07_storage.sql` | مخازن الملفات وسياساتها |
| `full_schema.sql` | كل ما سبق مدمجًا بالترتيب |

ترتيب التشغيل عند إعادة البناء: `01 → 02 → 03 → 04 → 05 → 06 → 07`
(هذه سكربتات بنية فقط، بدون بيانات المستخدمين).
